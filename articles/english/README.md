# Published articles – English

Put the PDF files of published English articles in this folder. The website lists every `.pdf` here automatically on the **Beyond** page.

**How to add an article (from the GitHub website):**

1. Open this folder on GitHub (`articles/english`).
2. Click **Add file → Upload files**.
3. Drag in the PDF and click **Commit changes**.

The file name becomes the title on the website, so name it clearly, for example `2025-Drip-irrigation-in-pomegranate-Agrowon.pdf`. Use `-` or `_` instead of spaces.
